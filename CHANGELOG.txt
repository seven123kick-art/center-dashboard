便別採算 データ復元経路 根本修正 2026-08-15

変更ファイル
- src/app.js
- src/core/repository/sync_coordinator.js

修正内容
1. 起動同期時に full_state を取得し、routeData（配達持出PDF解析結果）・companyMaster・workerMaster を復元するよう修正。
2. mergeFullState() が companyMaster / workerMaster を落としていたため、クラウド優先・ローカルフォールバックでマージ対象に追加。
3. 月別CSV本体（workerCsvData / productAddressData）は従来どおり年度別遅延取得。収支datasetsも既存Manifest経路のまま。計算式は変更なし。

原因
- routeData / companyMaster / workerMaster は full_state に保存される設計だが、Repository版syncBootでは full_state を通常取得していなかった。
- さらに mergeFullState() に companyMaster / workerMaster が含まれていなかった。
- そのため別端末・キャッシュ消失後に、他分析は月別CSVから復元できても便別採算だけ配達持出PDFなし・所属会社なしになり得た。

確認
- node --check src/app.js : PASS
- node --check src/core/repository/sync_coordinator.js : PASS
- LEDGERの売上/傭車支払/一次利益計算は変更なし
- route_analysis.jsの表示・Excel計算は変更なし

注意
クラウドfull_state自体にrouteDataが一度も保存されていない場合、この修正だけで過去の配達持出PDF解析結果を生成することはできません。その場合は配達持出PDFの再取込が必要です。
