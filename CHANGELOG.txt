配送分析 商品カテゴリ切替時の表示対象ちらつき修正
2026-08-15

変更ファイル
- src/field/field_product.js

原因
- 商品カテゴリ専用render()が #view-field-product 全体を innerHTML で再描画していた。
- field_core.js が管理する共通DOM #field-common-selector-box（表示対象）も同じview内に移設されるため、商品カテゴリ再描画時だけ一度破棄され、その後再生成・再配置されていた。
- この再配置が切替時の一瞬の位置ずれとして見えていた。

修正
- 商品カテゴリ再描画前に共通「表示対象」DOMを退避し、再描画直後に同じDOMを先頭へ戻す。
- 共通セレクタの値・イベント・年度月ロジックは変更しない。

無変更
- 商品カテゴリ集計ロジック
- 年度/月選択ロジック
- field_core.js
- navigation.js
- 他の配送分析5タブ
- STATE / STORE / Cloud / Repository / SyncCoordinator

検証
- node --check PASS
- 修正範囲は render() 内の共有DOM保持処理のみ
