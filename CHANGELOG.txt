Version6 D4-6 / Startup Readiness Gate
Date: 2026-08-17

PURPOSE
- Prevent cached/partial management figures from appearing before current cloud data is verified.
- Make visible figures mean startup verification completed successfully.
- On failure, missing data, or timeout, block numeric display and explain the state.

DISPLAY RULE
1. Center selected.
2. Local settings/cache may load internally, but numeric screens are not rendered.
3. Startup sync verifies manifest, full_state, required fiscal-year datasets, and manifest-declared plan/capacity/daily data.
4. Only READY renders the requested screen.
5. LOAD_FAILED / MISSING / timeout keeps figures hidden and shows a blocking dialog.
6. Successful startup shows a small "データ確認済" timestamp badge.

IMPORTANT
- Removed the former 45-second fallback that displayed local cache.
- Removed cache-first rendering followed by cloud number replacement.
- full_state/monthly fetch failures are no longer silently ignored.
- Missing cloud data without a valid fallback is MISSING, not successful empty startup.
- Business calculations and schemas are unchanged.
