Version6 D4-3 Preview Theme Rebuild
Date: 2026-08-17

PURPOSE
- Replace the blue/dark enterprise visual direction from D4-1/D4-2.
- Produce the first visual sample before applying the design to all screens.
- Target: center selection, shared shell/sidebar/topbar, and home dashboard.

DESIGN DIRECTION
- Bright modern UI.
- Pastel accents with restrained polish.
- Friendly enough to make daily use pleasant, while remaining appropriate for management meetings.
- No Taisho-romantic / Japanese-modern theme in this system.
- No direct reproduction of Hololive logos/character artwork as UI decoration.
- Center personality is expressed abstractly through color rhythm and atmosphere.

CENTER THEMES
- Kitasaitama: soft green as the main accent, with lilac/rose/sun/sky supporting pastels. Inspired by the user's Raden + ReGLOSS preference.
- Toda: warm cream/yellow/orange main accent with green/rose/lilac supporting pastels. Inspired by the user's Korone + hololive GAMERS preference.
- Layout/components remain the same product; only theme tokens differ.

CHANGES
- foundation/base.css: replaced dark-blue tokens with warm neutral surfaces and pastel center tokens.
- foundation/shell.css: changed sidebar from dark navy wall to a light, low-pressure shell; active state is a soft center-colored highlight.
- foundation/theme.css: cards/KPIs/buttons/forms/tables/messages rebuilt around warm neutral surfaces and pastel accents.
- landing.css: center selection rebuilt as the first visual sample with distinct but related Kitasaitama/Toda personalities.
- dashboard.css: home cards receive a lighter, more playful-but-professional presentation.
- dashboard.js: home chart palette changed from navy/red/green to green/rose/lilac.
- src/app.js: shared chart palette and center colors changed to the new pastel system.
- center.html: home chart legend swatches aligned with the new palette.

SCOPE
- This is intentionally a visual sample, not full-screen rollout.
- Business logic, data model, Data Catalog, Repository, Canonical, Supabase and import logic are unchanged.
- Other feature screens may still contain legacy blue hard-coded colors. They are intentionally left for the next rollout after visual approval.

VALIDATION
- All src/**/*.js syntax checks PASS.
- HTML parse checks PASS for index.html and center.html.
- CSS brace balance PASS for changed stylesheets.
