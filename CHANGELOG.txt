Version6 D4-22 / Route Profitability Canonical Read Path
Date: 2026-08-17

目的
- 便別採算を、旧STATE/LEDGER直読みに固定された画面からCanonical優先の読取経路へ移行。
- UI自身にCanonical Entity結合ロジックを持たせず、専用Read Adapterで分離する。

変更
1. CanonicalRouteLedger新設
   - CANONICAL_MATERIALIZERのVerified CURRENT SOURCEから便別採算用Read Modelを生成。
   - DELIVERY_ROUTE / ROUTE_WORKER / DELIVERY_ATTEMPT / BUSINESS_SLIP /
     SALES_DETAIL / ROUTE_PAYMENTを結合。
2. 便別採算
   - 月表示時にCanonicalRouteLedgerを優先。
   - Canonical SOURCEが存在しない移行前月のみLegacy LEDGERへfallback。
   - Canonical再構築失敗時も画面を完全停止せずLegacy互換表示へfallbackし、理由を明示。
3. データ経路を画面上に表示
   - Canonical
   - 旧データ互換表示 + fallback理由
4. 取込後はCanonical Route cacheもinvalidate。
5. 採算確定条件
   - 売上明細がCanonicalで確認できる
   - ROUTE_PAYMENTがNO_RECORDでない
   - 原票が便へ結合されている
   上記を満たす便のみ一次利益を確定表示。
   UNKNOWN/未連動を0円扱いしない。

重要
- Legacy LEDGERは削除しない。正規化SOURCE未登録の過去月互換用として保持。
- SOURCE/Canonical schema/Data Catalog/Supabase schemaは変更なし。
- D4-11高速起動は変更なし。
